🧿 Promper — Never Lose a Great Prompt Again

**Promper** is a fast, calm, and focused **Prompt Saver & Organizer** built for people who use AI daily and want to **reuse, refine, and remember** their best prompts — without clutter, complexity, or noise.

It’s not a notes app.  
It’s not a prompt generator.  
It’s your **personal prompt memory system**.

---

## ✨ Why Promper?

Most AI users face the same silent problems:

- “I wrote this prompt before… where is it?”
- “My good prompts are scattered everywhere.”
- “Chat history is useless for long-term reuse.”

Promper solves this by making prompt saving:

- ⚡ **Instant**
- 🧠 **Organized**
- ♻️ **Reusable**

So your best prompts become **assets**, not forgotten text.

---

## 🧩 Core Features

### ⚡ One-Click Prompt Saving
Save any prompt in seconds.  
No forms. No friction. Just paste and save.

---

### 🗂 Smart Organization
- Categories for broad grouping  
- Tags for flexible thinking  
- Fast filtering and browsing  

Find what you need in under 2 seconds.

---

### 🕘 Prompt Version History
Edit without fear.

- Every meaningful edit creates a version
- Restore old versions anytime
- No complex controls — it just works

---

### 🔁 Variables (Prompt Templates)
Turn static prompts into reusable templates:
Write a {{tone}} YouTube script about {{topic}}


Fill once, reuse forever.

No coding. Just “fill in the blanks”.

---

### 📋 One-Click Copy + Usage Count
- Copy instantly
- See how often you reuse a prompt
- Builds trust in what actually works

---

### 🌐 Cloud + Guest Mode
- Use Promper without signing up
- Save locally in guest mode
- After login, migrate prompts safely to cloud

Your data is always yours.

---

### 📤 Shareable Prompt Links (Viral by Design)
Share clean prompt pages with anyone.

Perfect for:
- Communities
- Tutorials
- Teams
- Friends

Every share brings new users — naturally.

## 🏗 Tech Stack

### Frontend
- HTML
- CSS
- Vanilla JavaScript

### Backend
- Supabase (PostgreSQL + Auth + RLS)

### Storage Strategy
- Guest Mode → LocalStorage
- Logged In → Supabase Cloud Sync

Designed to be:
- Lightweight
- Fast
- Offline-tolerant
- Scalable

---

## 🔒 Privacy & Security

- No selling of user data
- Supabase handles authentication
- Row Level Security protects prompts
- Guest data stays only on your device

Your prompts are private by default.
